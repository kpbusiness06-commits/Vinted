# Vinted Seller Studio 💗

A little business command center for a Vinted seller — Pastel Pop edition.

**What it does**
- Monthly goal as the big headline number, set a different target each month (default $1,400)
- Weekly goal (Sunday–Saturday) underneath it, set a different target each week
- Daily sales entry — tap any day, or use the quick entry on Home
- Auto calculations: weekly total, % of goal, amount left, daily average, sales days
- Week navigation and full weekly history
- Insights: all-time totals, goals reached, weekly totals chart, best week/day, strongest weekday
- Auto-saves on the device (local storage — entries live on the phone that entered them; no sync between devices in this version)

**Design**
Soft, playful, bright: lavender goal card, blush pink accents, mint and peach stat cards, creamy white background, rounded cards.

**Tech**
One file — `index.html` (HTML/CSS/JavaScript, no build step). Hosted on GitHub Pages.
